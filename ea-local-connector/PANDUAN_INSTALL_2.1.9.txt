ZENCORE CONNECTOR 2.1.9 / EA 2.16 — PANDUAN KEMAS KINI

HAD TF2 TERKINI
ATR8. Jarak SL = minimum antara ATR8 dan 4.00 USD dari harga entry.
TP1 maksimum 1.50; TP2 maksimum 2.50; TP3 maksimum 3.50 USD.
Ini jarak harga XAUUSD, bukan had kerugian akaun. Lot/layer menentukan
jumlah risiko akaun. Had baharu untuk setup baharu; SL posisi sedia ada
tidak dilebarkan. TF15 kekal mengikut pelan ATR14.

SEBELUM KEMAS KINI
Tunggu tiada order sedang dihantar. Sebaiknya tunggu posisi ZenCore kosong.
Gunakan Windows user yang sama dengan MT5. Tidak perlu reset link akaun,
ubah lot/layer atau masukkan password broker dalam Connector.

1. Jalankan ZenCoreSetup-2.1.9.exe.
2. Dalam MT5 pilih File > Open Data Folder. Pilih folder MT5 itu di Connector.
3. Tekan Pasang / kemas kini EA 2.16. Jika compile gagal, jangan guna EX5 lama.
4. MT5 Navigator > Refresh > Expert Advisors > ZenCore > ZenCoreExecutor.
5. Gantikan EA lama dengan EA baharu pada SATU chart XAUUSD.
6. Hidupkan Algo Trading dan Allow Algo Trading. DLL/WebRequest tidak perlu.
7. Jika diminta, login menggunakan akaun web ZenCore sendiri.
8. Semak akaun MT5, REAL/DEMO dan server sebelum pautkan akaun.
9. Semak status Terminal, Cloud dan Entry. Lot/layer/ON-OFF dibuat di web.
10. SERVER PAUSED bermaksud entry dikunci sistem pusat; jangan bypass.

PINE / ALERT (ADMIN SUMBER DATA)
Pasang Pine TF2 V3.5 terkini pada chart 2 minit. Cipta semula kedua-dua
alert Dashboard dan Execution menggunakan Pine baharu dan webhook/secret
sedia ada. Alert TradingView lama tidak berubah apabila script di chart diubah.
EA 2.16 dan Pine V3.5 diperlukan untuk menggunakan penuh had SL4.
Pine/EA lama masih serasi tetapi boleh mengekalkan had SL lama.

PENGURUSAN POSISI
Entry/re-entry dan kenaikan tahap step-lock TF2 menggunakan candle tutup.
SL broker tetap aktif setiap tick. BUY tidak masuk pada/selepas TP1;
SELL tidak masuk pada/selepas TP1 mengikut arah jual. Setiap layer disemak
berdasarkan quote dan fill sebenar. Fill yang tidak dapat dilindungi boleh
ditutup segera. Slippage/gap masih boleh berlaku.

TP1 TF2 mengunci entry +1.50 mengikut arah apabila harga melepasi paras lock;
TP2 -> SL TP1; TP3 -> SL TP2; lebih TP3 +3.00 -> SL TP3.
Lock tidak diletakkan lebih buruk daripada fill sebenar. SL tidak dilonggarkan.
TF15: TP1 -> SL entry, TP2 -> SL TP1, TP3 -> SL TP2; tiada tambahan +3.
Signal native Close Separuh / Close All mengikuti polisi exit sistem semasa.

SEKATAN LIBAS TF2
ATR8 >4.5 atau <1.5 DAN minimum dua perubahan arah dalam enam candle
tertutup. Sekatan dinilai semula setiap close. Lepas jika ATR kembali
1.5–4.5 atau perubahan arah kurang dua. Pelepasan bukan arahan entry;
SOP asal dan signal baharu yang sah masih diperlukan.

JIKA TUKAR AKAUN
Reset link / tukar akaun menghentikan pautan dan boleh mengosongkan setting
web. Ia tidak menutup posisi broker. Login akaun baharu di MT5, tunggu EA
mengesan akaun dan pautkan semula. Jangan reset hanya untuk update versi.

Butang X minimize Connector. Gunakan Keluar Connector untuk menghentikannya.
Jangan kongsi password, token atau fail konfigurasi akaun dengan orang lain.
