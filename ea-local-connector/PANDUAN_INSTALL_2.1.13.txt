ZENCORE CONNECTOR 2.1.13 / EA 2.17 — KEMAS KINI LEASE

PEMBAIKAN
Connector memperbaharui lease selepas semakan tandatangan arahan PLACE_SETUP,
sebelum menyerahkannya kepada EA. STOP dan perubahan sesi MT5 tetap dihormati.
Signal luput tidak dipanjangkan. Tiada order lama dihantar semula secara automatik.
EA 2.17 dikekalkan. Tidak perlu ubah Pine, lot/layer atau pautan akaun untuk pembaikan ini.

CARA KEMAS KINI NORMAL
1. Tunggu tiada arahan sedang dihantar; sebaiknya posisi ZenCore sudah kosong.
2. Keluar Connector lama melalui menu Keluar, bukan hanya butang X.
3. Jalankan ZenCoreSetup-2.1.13.exe menggunakan Windows user yang sama.
4. Buka Connector. Semak build 2.1.13, akaun, server dan mode REAL/DEMO.
5. Pautan dan tetapan sedia ada dikekalkan. Jangan Reset Link hanya untuk update.
6. Pastikan MT5 tersambung, EA 2.17 pada satu chart, Algo Trading dan Allow Algo Trading ON.
7. Semak status Cloud/EA dan ON/OFF di web. Tunggu signal baharu yang sah.

UNTUK VPS
Gunakan ZenCoreVPSSetup-1.0.5.exe, bukan kedua-dua Connector serentak.
Keluar Manager lama sebelum installer. Buka semula dan semak setiap profil.
Kemas kini tidak menutup MT5 atau mengubah lot/layer. Semasa Connector berhenti,
SL broker kekal tetapi arahan cloud tidak boleh diproses. Pilih waktu update sesuai.

JIKA MASIH LEASE_NOT_READY
Semak sambungan internet, waktu Windows automatik, akaun/server MT5, Cloud dan EA.
Pastikan satu Connector sahaja mengurus akaun tersebut dan sesi Windows sama.
Catat masa, build dan status untuk admin. Jangan salin token atau fail lease.
Pembaikan ini tidak menjamin sambungan jika internet/MT5 terputus.

SOP LIVE
Initial entry TF2/TF15 mengikuti native Solid Entry V7.1 pada candle tutup.
Re-entry, SL/TP dan exit kekal mengikut SOP server semasa.
TF2 ATR8: jarak SL maksimum 4.00 USD; TP maksimum 1.50/2.50/3.50 USD.
TF15 mengikut pelan ATR14. Jarak harga bukan had kerugian akaun.
SL broker tetap aktif intrabar; slippage/gap masih boleh berlaku.
Auto Exit manual: medan kosong guna jarak default TP1/TP2/TP3/SL = 2/4/6/3.
Pelan posisi manual sedia ada dikekalkan selepas tetapan baharu disimpan.

Tiada order broker atau mesej Telegram sebenar dihantar dalam ujian pakej.

RESET CONNECTOR / TUKAR CLIENT
1. OFF Auto Trade akaun lama di web. Selesaikan posisi ZenCore dan tunggu arahan MT5 selesai.
2. Klik Reset Connector dan sahkan. Tidak perlu password client lama untuk reset setempat.
3. Connector berhenti, lease dibatalkan, token/diagnostik setempat dipadam dan medan login dikosongkan.
4. Login MT5 client baharu. Tekan Cari akaun, isi ID/e-mel serta password ZenCore client baharu.
5. Semak akaun/server/mode dan Pautkan. Lengkapkan setup/serahan admin melalui web seperti biasa.
6. Jika menggunakan semula ID ZenCore lama, pastikan OFF dan tunggu sekurang-kurangnya 2 minit
   sejak Connector lama berhenti. Jika ditolak OLD_CONNECTOR_ACTIVE, semak tiada Connector lain berjalan.

Reset ini untuk data Connector pada PC ini. Akaun web, password web, profil dan rekod broker kekal.
Ia tidak melakukan Reset Akaun admin. Fail perlindungan EA/SL dan heartbeat tidak dipadam.
Tiada posisi ditutup dan Auto Trade tidak dihidupkan oleh reset atau pautan baharu.
Reset ditolak jika EA offline, terminal terputus, posisi masih ada, atau arahan/pengesahan belum selesai.
Jika ditolak, pautan dikekalkan dalam keadaan berhenti. Selesaikan punca dan klik Reset semula.
Jika perlu sambung operasi, buka semula Connector; semak OFF/ON di web dahulu.

PEMBAIKAN FOLDER MT5 / EA
Boleh pilih data folder atau subfolder MQL5. Folder program MT5 biasa dipadankan
ke data folder melalui origin.txt apabila hanya satu padanan tersedia.
Jika lebih satu padanan, pilih tepat melalui File > Open Data Folder.
Jika MetaEditor tidak ditemui, pilih metaeditor64.exe melalui dialog yang dipaparkan.
Bukan terminal64.exe. Fail EX5 mesti dihasilkan sebelum pemasangan dianggap berjaya.
Ralat folder, compile, permission atau timeout kini diterangkan berasingan daripada pautan.
