ZENCORE CONNECTOR 2.1.28 / EA 2.28

1. Tutup aplikasi Connector lama sahaja. Jangan reset pautan akaun.
2. Jalankan ZenCoreSetup-2.1.28.exe dan buka ZenCore Connector.
3. Gunakan pautan akaun sedia ada. Pilih folder MT5 yang betul.
4. Tekan Pasang / kemas kini EA 2.28 dan pastikan Experts menunjukkan EA_READY version=2.28.
5. Semak sambungan web dan tetapan ON/OFF sebelum menggunakan auto trade.

Pine Native V7 TF2/TF15 -> EA. Entry tidak luput berdasarkan umur signal.
Beza mutlak harga Ask/ Bid dengan entry pelan Pine >= USD4: sekat entry.
SL dan setiap TP bermula daripada harga fill sebenar setiap posisi, dengan jarak pelan Pine.
Setiap event hanya sekali; arahan pendua tidak membuka order baharu.
EA menghantar satu order bagi setiap layer. Akaun netting menggabungkan fill setup yang sama.
Jika fill broker melepasi had, EA cuba tutup posisi dan melaporkan kejadian.

Pakej ini tidak mengandungi password atau pautan akaun pengguna.

Auto Exit manual: OFF menghentikan pengurusan EA; SL/TP broker sedia ada kekal. Tick/untick di web dihantar terus. Simpan TP/SL Manual untuk tetapan posisi baharu.

Pine Direct menggunakan simbol carta MT5 tempat EA dipasang. EA menunggu harga Bid/Ask sehingga 4 saat.

ENTRY MANUAL AUTO EXIT: TP1 -> SL entry; TP2 -> SL TP1; TP3 -> SL TP2; 2.00 melepasi TP3 -> SL TP3. TP broker dikosongkan pada posisi diambil alih. Tiada exit daripada signal Pine untuk mod manual ini.

Pemulihan rangkaian: Connector cuba semula selepas gangguan sementara.
