ZENCORE CONNECTOR 1.25 / EA 1.26 — WINDOWS, REAL + DEMO

Satu installer yang sama untuk setiap client. Setiap client login akaun ZenCore
sendiri dan pautkan MT5 sendiri. Jangan salin paired.dpapi dari PC lain.

KEMAS KINI
1. Di web tekan STOP ENTRY. Ini bukan Close All.
2. Tutup Connector lama. Biarkan posisi sedia ada dikendalikan dengan berhati-hati.
3. Jalankan ZenCoreSetup-1.25.exe menggunakan Windows user yang sama dengan MT5.
   Tidak perlu Run as Administrator.
4. MT5: File > Open Data Folder. Salin lokasi folder yang dibuka.
5. Connector: pilih folder tadi, klik Pasang / Kemas kini EA.
6. Tunggu compile berjaya. Jika gagal, semak compile.log dalam
   folder MQL5/Experts/ZenCore yang sama.
7. Tanggalkan EA lama. Navigator > Refresh. Pasang ZenCoreExecutor
   pada SATU chart sahaja untuk akaun ini. Jangan pasang dua salinan.
8. Hidupkan Algo Trading. Dalam Experts, cari EA_READY version=1.26.
9. Connector: Cari akaun MT5. Pilih akaun sendiri. Client baru login
   akaun ZenCore sendiri dan klik Login & pautkan akaun.
   Pautan lama yang masih sah boleh dikekalkan selepas upgrade.
10. Web: semak akaun bertopeng, sambungan READY, lot/layer TF2 dan TF15.
    Lot atau layer kosong = tiada entry untuk TF itu selepas Simpan.
11. Simpan konfigurasi. Hidupkan Auto Trade apabila bersedia.
    Akses execution mestilah dibenarkan untuk akaun ZenCore client.

JIKA EA GAGAL MASUK CHART
Buka MT5 Toolbox > Experts. Salin baris ZenCore sebelum INIT_FAILED.
INIT_FOLDER_FAILED: folder Common Files tidak dapat dibuat.
INIT_LOCK_FAILED: EA lain memegang kunci atau fail tidak dapat dibuka.
INIT_HASH_FAILED: hash identiti server gagal.
INIT_HEARTBEAT_FAILED: heartbeat tempatan gagal ditulis.
INIT_TIMER_FAILED: timer MT5 gagal bermula.
SERVER_NOT_ALLOWED: server bukan salah satu nama di atas.
unsupported account mode: akaun bukan mode REAL atau DEMO yang disokong.

PC/VM, MT5 dan Connector mesti terus hidup. HP/tablet mengawal web sahaja.
Password broker hanya dimasukkan dalam MT5. DLL/WebRequest tidak diperlukan.
Installer tidak membuka order ujian. MQ5 di-compile oleh MetaEditor pada PC client.
