ZENCORE — PEMASANGAN MUDAH EA 1.21 (WINDOWS, DEMO)

Jika sudah menggunakan versi lama:
1. Di web ZenCore, tekan STOP ENTRY dan tunggu status STOPPED.
   STOP ENTRY bukan Close All. Jangan tekan Emergency Close All untuk upgrade.
2. Tutup ZenCore Connector lama.
3. Double-click ZenCoreSetup-1.21.1.exe. Ikut Install -> Finish.
   Gunakan Windows user yang sama dengan MT5. Tidak perlu Run as Administrator.

Pasang EA:
4. Buka MT5 desktop dan login akaun DEMO broker anda.
5. MT5 -> File -> Open Data Folder. Salin lokasi folder tersebut.
6. Dalam ZenCore Connector, pilih folder tadi.
7. Klik Pasang / Kemas kini EA 1.21. Connector akan compile sendiri.
8. Selepas berjaya: MT5 Navigator -> Refresh -> Expert Advisors -> ZenCore.
9. Jika ada EA lama pada chart, tanggalkannya. Pasang ZenCoreExecutor pada
   SATU chart sahaja. Semua pair dan TF diurus oleh EA ini.
10. Hidupkan Algo Trading. DLL dan WebRequest tidak diperlukan.

Pautkan akaun:
11. Klik Cari akaun MT5 dan pilih akaun DEMO anda.
12. Pengguna baharu: login dengan akaun ZenCore dan klik Login & pautkan akaun.
    Pengguna yang sudah dipautkan: kekalkan pautan sedia ada jika status READY.
    Password broker hanya dimasukkan dalam MT5.
13. Klik Buka ZenCore. Pilih TF2, TF15 atau Both; pilih pair, lot dan layer.
14. Simpan konfigurasi, kemudian hidupkan Auto Trade sendiri apabila bersedia.
15. Sahkan MT5 READY, Auto Trade ON dan EA aktif pada chart.

Biarkan MT5 dan Connector berjalan serta PC/VM online.
HP/tablet boleh mengawal web; EA berjalan pada PC/VM Windows.
TF2: HEMA2 + HEMA3. TF15: HEMA15 + HEMA30.
Posisi dua TF berasingan pada pair sama memerlukan akaun MT5 hedging.
Pakej ini DEMO sahaja. Installer tidak membuka order ujian.

Connector 1.21.1: masa arahan mengikuti server; kod penolakan sebenar dipaparkan.
Jika EA 1.21 sudah aktif, tidak perlu pasang EA semula. Tutup Connector lama,
install kemas kini dengan Windows user yang sama, dan buka Connector baharu.
Pautan sedia ada dikekalkan. Tiada password broker diminta.

KEMAS KINI REAL + DEMO: Connector 1.22, EA 1.23
1. Install ZenCoreSetup-1.22.exe pada PC/VM Windows yang menjalankan MT5.
2. Login akaun broker yang hendak digunakan dalam MT5.
3. Dalam Connector klik Pasang / Kemas kini EA 1.23. Refresh Navigator MT5.
4. Pasang EA baru pada satu chart dan hidupkan Algo Trading.
5. Cari akaun MT5; pilih akaun REAL atau DEMO yang betul dan link login ZenCore sendiri.
6. Buka web ZenCore (Android pun boleh). Semak akaun bertopeng dan MODE.
7. Simpan lot/layer/TF; tekan ON. REAL guna AKTIFKAN REAL; DEMO guna AKTIFKAN DEMO.
Akaun yang lama tidak ditukar atau dihidupkan secara automatik. Jika hendak tukar akaun: OFF dan selesaikan posisi ZenCore dahulu, tutup Connector lama dan pautkan semula.
