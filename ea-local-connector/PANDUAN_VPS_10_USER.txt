ZENCORE VPS MANAGER 1.1.5
Connector 2.1.21 / EA 2.22
Status Auto Trade dikawal dari ZenCore web.

ALIRAN ADMIN
0. Isi ID + password ADMIN, klik Sahkan Admin. Password tidak disimpan.
1. Pada slot yang betul, klik 1 Folder / EA dan tampal alamat MT5 > File > Open Data Folder.
   Folder yang sudah disimpan akan diisi semula. Kosongkan kotak untuk membuka senarai terminal.
   Manager menyalin ZenCoreExecutor.ex5 yang sudah dikompil. MetaEditor tidak diperlukan.
2. Dalam MT5, Refresh Navigator dan attach ZenCoreExecutor pada SATU chart sahaja.
   Login broker dibuat dalam MT5; password broker tidak diberikan kepada Manager.
   Hidupkan Algo Trading dan pastikan akaun/server betul.
   Klik Cari semua MT5. EA 2.22 membolehkan padanan folder dibuat secara automatik.
   Isi ID ZenCore client pada slot, kemudian klik 2 Sambung EA.
   Admin tidak perlu password client untuk laluan ini.
3. Klik 3 Auto Trade. Browser membuka halaman setup admin untuk client tepat.
   Login admin di browser jika diminta; simpan lot/layer/TF, waktu dan pilihan exit.
4. Selepas MT5 READY, konfigurasi lengkap, Auto Trade STOP dan tiada posisi:
   Admin membuka serahan pada halaman client. User melengkapkan profil dan password baharu.
   Sebelum serahan, akses trading user kekal terkunci.

TUKAR USER / AKAUN PADA SLOT SAMA
- Sahkan Admin, kemudian klik Kosongkan pada slot berkenaan.
- Pengesahan ini menggunakan Master Reset akaun client yang terikat pada slot.
- Profil/settings ZenCore kembali asal dan password zc123. ID asal dikekalkan.
- SEMUA posisi/pending order akaun MT5 itu, termasuk manual/EA lain, akan cuba ditutup/dibatalkan.
  Untung/rugi boleh direalisasikan. Admin mesti menyemak pengesahan sebelum meneruskan.
- Jika EA offline, pautan sistem dilepaskan tetapi posisi broker BELUM DISAHKAN tutup.
  Amaran dipaparkan; admin perlu semak MT5. Jangan anggap broker sudah kosong.
- Selepas slot kosong, tunggu 30 saat, pilih folder/akaun dan ID client baharu.
- Slot lain dan fail perlindungan EA tidak dipadam oleh pembersihan slot tempatan.
- Jika token lama sudah dibatalkan, hanya data slot tempatan lama dibersihkan; akaun baharu tidak direset.

PEMULIHAN SAMBUNGAN
- Ralat internet/lease sementara dicuba semula secara terkawal; tidak perlu OFF/ON berulang.
- Selepas restart MT5/EA, ON terdahulu hanya dipulihkan untuk pemilik/account sama,
  selepas lease baharu sah dan permission broker lengkap.
- OFF disengajakan, akaun terkunci/tamat tempoh dan SERVER PAUSED tidak dipintas.
- Akaun/token salah dan permission broker memerlukan pembetulan admin.
- Tiada order lama dihantar semula. Setiap order masih perlu signal baharu yang sah.

KELAJUAN DAN UJIAN
Command diberi keutamaan sebelum kerja pengurusan berkala EA.
Polling Connector 0.5s dan timer EA 250ms bukan jaminan order tiba dalam tempoh itu.
Internet, server, CPU/RAM VPS dan broker masih mempengaruhi masa sebenar.
Semak execution-timing.jsonl dan log Experts untuk mengukur.
Uji satu persekitaran kosong dahulu. Jangan naik taraf semua client atau live sebelum disahkan.
Jika skrin kecil, gunakan scrollbar jadual untuk semua slot dan butang.
